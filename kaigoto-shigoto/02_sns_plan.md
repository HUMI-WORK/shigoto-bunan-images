# SNS導線設計と投稿スケジュール（2026/11/28 〜 12/31）

## 1. 導線の全体像

```
【知ってもらう】  TikTok ／ Instagramリール
        ↓  （プロフィールに飛ぶ／保存される）
【信頼してもらう】Instagramカルーセル ／ Threads ／ X
        ↓  （プロフィールのリンク・投稿内のリンク）
【読んでもらう】  note無料記事（体験＋制度の解説）
        ↓  （記事の最後に有料記事への導線）
【買ってもらう】  note有料¥500 → マガジン¥1,480
```

**原則：SNSでは「悩みを言葉にする」「文例を1つだけ見せる」までにとどめ、全部を見せるのはnoteにする。**

## 2. 各SNSの役割

| SNS | 役割 | 主な形式 | noteへのつなぎ方 | 一番の指標 |
|---|---|---|---|---|
| **TikTok** | 知ってもらう（30〜50代にも届く） | 写真のスライドショー（カルーセル画像を流用）＋文字だけの短い動画 | プロフィールのリンク。※TikTokはリンクを貼るのに条件がある（ビジネスアカウントやフォロワー数など）。使えない間は「Instagramで『かいごとしごと』と検索」と誘導する | 再生数・プロフィールへのアクセス |
| **Instagram** | 保存されて信頼される（メインの受け皿） | カルーセル（文例・チェックリスト）、リール、ストーリーズ | プロフィールのリンク＋**ストーリーズのリンクスタンプ**（有料記事の公開日）。余裕があれば「『文例』とコメントするとDMでリンクが届く」自動返信も使う | 保存数・プロフィールのリンクのクリック |
| **Threads** | 共感と会話、投稿ネタ集め | 短い本音の投稿、質問の募集 | 投稿にリンクを貼れる（週2回まで。宣伝ばかりにならないように） | 返信数・フォロー |
| **X** | note読者がいちばん多い場所。告知と拡散 | 1つの投稿＋スレッド形式、noteの共有 | 記事の公開日にスレッドで告知（リンクは返信のほうに貼る）。プロフィールの固定投稿は最新の有料記事 | リンクのクリック・note経由のフォロー |

## 3. 「1ネタ4媒体」で回す（作る手間を最小にする）

毎週のテーマ（`01_note_plan.md`）から **カルーセル1枚（5〜7枚組）を「元ネタ」にして使い回します。**

| 元ネタ | 使い回し先 |
|---|---|
| カルーセル画像（1080×1350） | Instagramのフィード → 同じ画像で TikTok の写真投稿 |
| カルーセルの1枚目＋読み上げ | リール・TikTok動画（文字アニメ＋BGM、15〜30秒） |
| カルーセルの本文 | Xのスレッド（1枚につき1投稿） |
| カルーセルを作るまでの本音・体験 | Threads |

**1週間あたりに作るもの：カルーセル3本と短い動画2本だけ。** あとは文字の投稿です。

## 6. 気をつけること

- **医療や法律の判断は断定しない。** 「会社の就業規則と、地域包括支援センターで確認を」を定型文にしておく
- 親の顔、名前、病名などが特定できる情報は出さない（写真は手元や風景だけにする）
- 宣伝の投稿は全体の2割まで。8割は「無料で役に立つ」投稿にする
- コメントやDMで届いた悩みは、本人の許可を得てから匿名で記事のネタにする（noteの1月以降の追加記事に回す）
