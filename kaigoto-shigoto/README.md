# かいごと しごと ― 新アカウント立ち上げ一式

「しごと文案室」とは別の新アカウントとして立ち上げる前提のプランです。

## コンセプト

**親の介護が始まった会社員が「辞めずに働き続ける」ための、伝え方・申請・交渉のテンプレート**

構造 = 「当事者の物語（フィクションの主人公ミサキ）」×「会社員の実務（交渉・制度・伝え方）」×「¥500テンプレ集 → マガジン化」

## アカウント設定（全SNS共通）

## 物語はフィクション、文例と制度は本物

体験談はありません。そのため、**架空の主人公「ミサキ」（42歳・独身・2人姉妹の長女・妹は介護に関わらない）の連載ストーリー** として書きます。設定は [00_persona.md](00_persona.md) にまとめ、全記事・全SNSで同じ設定を使います。

- 各記事に「ミサキの物語はフィクションです」と必ず明記する（実体験だと誤解させて売らない）
- 書き手は「ミサキ本人」ではなく、物語と文例をまとめる編集役として書く
- 物語で共感してもらい、文例と制度の解説で役に立つ。購入者が受け取る価値（文例）は本物にする
