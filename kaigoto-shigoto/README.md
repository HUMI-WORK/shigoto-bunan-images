# かいごと しごと ― 新アカウント立ち上げ一式

「しごと文案室」とは別の新アカウントとして立ち上げる前提のプランです。

## コンセプト

**親の介護が始まった会社員が「辞めずに働き続ける」ための、伝え方・申請・交渉のテンプレート**

構造 = 「当事者の体験」×「会社員の実務（交渉・制度・伝え方）」×「¥500テンプレ集 → マガジン化」

## アカウント設定（全SNS共通）

| 項目 | 案 |
|---|---|
| アカウント名 | かいごと しごと｜介護で辞めない会社員の文例帳 |
| ID（共通） | `kaigoto_shigoto`（取れなければ `kaigoto.shigoto` / `kaigoto_note`） |
| ひとこと | 親の介護 × 会社員。上司への伝え方・申請・働き方交渉を「そのまま使える文例」にしています。 |
| プロフィール文（note） | 親の介護が始まった会社員です。介護休業・介護休暇・在宅勤務の交渉など、「会社にどう言えばいいか」で止まった経験を、そのまま使えるテンプレートにして残しています。介護離職を一人でも減らしたい。 |
| プロフィール文（SNS短縮） | 親の介護×会社員／上司への伝え方・申請・交渉の文例を毎日／辞めないための実務テンプレはnoteへ↓ |
| アイコン | 文字ロゴ（「かいごと しごと」2行・紺×生成り）。顔出し不要 |
| リンク | note のマガジン or 最新有料記事（lit.link等でまとめてもOK） |

## ⚠ 書き始める前に決めること：「当事者の体験」

この構造の強さは **実体験** です。下書きの中で `【体験メモ】` と書いた箇所は、ご自身（または取材した方）の実際の体験に差し替えてください。

- 介護の対象：誰を／いつから／距離（同居・近距離・遠距離）
- 最初に困ったこと（会社に言えなかった、申請が分からなかった、等）
- 実際に使った制度・言ったこと・言われたこと

体験がない場合は「当事者」ではなく「取材者」として、周りの方の体験談を許可を得て載せる形に切り替えましょう（作り話の体験談は信頼を失い、noteの規約上もリスクになります）。
