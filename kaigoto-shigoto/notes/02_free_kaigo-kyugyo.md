# 介護休業93日は「介護するための休み」じゃない。会社員が最初に知るべき使い方

> ※ミサキの物語は、介護と仕事の両立でよくある悩みをもとに創作したフィクションです。制度の解説と文例は、実際にそのまま使えるように書いています。

## ミサキの決心

母の手術から1週間。東京に戻ったミサキは、ひとつ決心をしました。

「介護休業を1か月取って、母のそばにいよう」

妹のユカは来られない。母には自分しかいない。
退院までの間、毎日病院に通って、退院後の生活も自分が支えればいい。

ミサキは人事部にメールを書きかけました。
**「介護休業を、11月の1か月間取得したいです」**

送信する前に、念のため人事の担当者に電話で確認しました。
返ってきたのは、思ってもいない質問でした。

「ミサキさん、お母さまの介護は、その1か月で終わりそうですか？」

ミサキは、答えられませんでした。

この考え方は、実は **介護休業の使い方としていちばん避けたいもの** に近かったのです。

## 介護休業は、通算93日しかない

介護休業は、対象の家族1人につき **通算93日まで、3回まで分けて** 取れる制度です。

93日はおよそ3か月です。
一方で、介護が続く期間は数年に及ぶことも珍しくありません。

つまり、**介護休業の期間で、介護そのものを全部やろうとすると、まったく足りない** のです。

## 介護休業は「介護の体制をつくる期間」

厚生労働省も、介護休業の目的を
**「仕事と介護を両立できる体制を整えるための期間」**
と説明しています。

使い方のイメージはこうです。

| やりがちな使い方 | 本来の使い方 |
|---|---|
| 休業して、自分が毎日介護をする | 休業中に、介護サービスや家族の分担を整える |
| 一度に93日を使い切る | 「最初の体制づくり」「状態が変わったとき」「施設を探すとき」などに分けて使う |
| 休業が終わったら、またゼロから考える | 休業が明けたら、仕事に戻れる状態にしておく |

休業中にやることは、たとえばこんなことです。

- 地域包括支援センターに相談する
- 要介護認定を申請する／調査に立ち会う
- ケアマネジャーを決めて、ケアプランを作ってもらう
- デイサービス、ヘルパー、ショートステイなどを決める
- きょうだいとの役割分担を決める
- 施設を見学する

**「自分が介護する」のではなく、「自分がいなくても回るしくみを作る」** ための休みだと考えると、93日の使い方が変わります。

人事の担当者から説明を受けたミサキは、計画を立て直しました。

| 当初の計画 | 立て直した計画 |
|---|---|
| 11月に1か月まとめて休業し、毎日病院に通う | 要介護認定の調査に立ち会う日を中心に、**5日だけ** 休業する（1回目） |
| 退院後のことは、退院してから考える | 退院前に、ケアマネジャーやデイサービスを決めておく |
| 93日のうち30日を一度に使う | 残りの88日は、退院するときと、状態が変わったときのために取っておく |

## 要介護認定が出ていなくても取れる

意外と知られていないのが、**介護休業は要介護認定がなくても取れる** ということです。

対象になるのは、ケガや病気、体や心の障害によって、**2週間以上にわたって常に介護が必要な状態** の家族です。
「まだ認定が出ていないから」と諦める必要はありません。

## 介護休業のほかにも、使える制度がある

介護休業だけで乗り切ろうとしないことも大事です。
会社員が使える主な制度をまとめます。

| 制度 | 内容 | 向いている場面 |
|---|---|---|
| 介護休業 | 対象家族1人につき通算93日、3回まで分割できる | 体制づくり、状態が急に変わったとき |
| 介護休暇 | 年5日（対象家族が2人以上なら10日）、**1時間単位で取れる** | 通院の付き添い、ケアマネとの面談 |
| 所定外労働の制限 | 残業をしない | 夕方以降に介護の予定がある |
| 時間外労働の制限 | 残業を月24時間・年150時間までにする | 残業を減らしたい |
| 深夜業の制限 | 22時〜5時に働かない | 夜勤がある職場 |
| 短時間勤務などの措置 | 時短勤務、フレックス、時差出勤など（会社が用意する制度から選ぶ。利用開始から3年以上の間に2回以上使える） | 毎日の送り迎えがある |

さらに、2025年4月の法改正で、**介護に直面したことを会社に伝えた社員には、会社が制度を個別に説明し、利用するかどうかの意向を確認することが義務** になりました。
また、介護をしている社員がテレワークを選べるようにすることが、会社の努力義務になっています。

「会社に言ったら面倒がられるかも」と思うかもしれません。
でも、**伝えることで、会社には説明する義務が生まれます。**

## 休業中のお金：介護休業給付金

雇用保険に入っていて条件を満たせば、介護休業中は **介護休業給付金** として、休業前の賃金のおよそ67%が支給されます（上限があります）。
休業がそのまま無収入になるわけではありません。条件や手続きは、勤務先の人事かハローワークで確認してください。

## まとめ：最初にやるのは「休む」ではなく「伝える」

1. 介護休業は、介護をする期間ではなく **体制をつくる期間**
2. 93日は **分けて使う** 前提で考える
3. 介護休暇（時間単位）、残業の制限、時短などを **組み合わせる**
4. 会社に伝えると、会社には **制度を説明する義務** がある

ということで、最初の一歩は「上司に伝えること」です。

ミサキはまだ、課長に「家の用事」としか伝えていませんでした。
意を決して課長に話したミサキに返ってきたのは、こんな一言でした。

「そうか、大変だね。無理しないでね」

そして、**何も決まらないまま、話は終わりました。**

次回（12/3）は、**上司に「親の介護」を伝える前に、決めておく3つのこと** を書きます。
